A tiny deterministic Python program (stdlib only, no network, no input)
that writes one original joke about office life — a single line — to
`/output/entry.txt`.

## Run

```sh
python3 main.py
```

## The joke

> I asked my boss for one quiet day to catch up, so he scheduled six meetings to discuss why I'm behind on my work.
